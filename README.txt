Deploy to Vercel:
1. Create a new GitHub repository (e.g. momo-1111).
2. Upload these two files to the repository root.
3. In Vercel, choose Add New > Project.
4. Import the new GitHub repository.
5. Framework Preset: Other.
6. Build Command: leave blank.
7. Output Directory: leave blank (or use ./).
8. Click Deploy.

The PDF link in index.html expects the PDF filename above to remain unchanged
and in the same root folder.
